/api/v1/licensing/validate
Validate a license file or key · 🌐 Public

Validates a license PEM file or license key. Returns tier, features, limits, and optional feature-availability check. No authentication required.

Request Body
"license_file": "-----BEGIN IRONWALL LICENSE-----\n...base64...\n-----END IRONWALL LICENSE-----", "feature": "geoip_blocking" // optional
JSON
Response 200
{ "valid": true, "tier": "ENTERPRISE", "licensee": "Acme Corp", "days_remaining": 312, "feature_available": true, "features": ["core_waf", "geoip_blocking", "siem"], "errors": [], "warnings": [] }
JSON
Response 403 — Invalid License
{ "valid": false, "errors": ["INVALID SIGNATURE — license has been tampered with"] }
JSON
